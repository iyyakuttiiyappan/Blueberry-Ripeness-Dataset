# Metadata Examples

This folder contains small metadata files.

- `class_map.json`: semantic label IDs and class names.
- `class_distribution.csv`: complete class-level object counts for the 514-image release.
- `split_summary.csv`: complete train/validation/test split summary.
- `dataset_manifest_sample.csv`: first 30 manifest rows, provided only as a schema example.
- `dataset_manifest_columns.csv`: full list of manifest columns.
- `image_level_counts_sample.csv`: first 30 image-level count rows.
- `SHA256SUMS_release_514.txt`: checksum list for verifying the separately hosted release files.

The complete `dataset_manifest.csv`, `image_level_counts.csv`, RGB images and masks are included in the deposited dataset archive.
