
Optional supplement:

```text
blueberry_ripeness_training_only_natural_synthetic_augmentation_v1.zip
```

The optional synthetic archive is provided only for training augmentation experiments. It should not be treated as additional independent real data.

The data repository also includes `SHA256SUMS.txt`, which can be used to verify that downloaded archives match the deposited files.
